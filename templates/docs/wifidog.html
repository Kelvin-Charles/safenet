SafeNetWiFiDog

WiFiDog is a standard way for a router or access point to ask a server who may use the internet. Many brands have it built in or can install it. Point it at SafeNet and new guests get your SafeNet login page, are let online after they pay or type a voucher, and are checked with SafeNet every minute. SafeNet sees each guest's data usage and cuts them off the moment their time ends or you press Disconnect.

This is the same connection Ruijie RG-AP access points use (see the Ruijie guide for their commands).

Which devices work

BrandHow
OpenWrt (any router that runs it)✅ Install a WiFiDog package (below). The most flexible choice.
Cudy✅ Cudy publishes OpenWrt for many of its routers (for example WR3000, X6, TR3000). Install it, then follow OpenWrt. Cudy's own firmware has no WiFiDog.
Comfast✅ Business access points, AC controllers and WISP routers that have a Portal or Authentication menu with WiFiDog. Check the menu or ask your seller before buying.
Wavlink✅ Business and outdoor models with a WiFiDog or external portal setting. Home models usually don't have it.
Tenda⚠️ Most models have no WiFiDog. Use them as plain access points behind a SafeNet gateway or a MikroTik.
Ruijie RG-AP, Reyee with WiFiDog✅ See the Ruijie guide.
Any other brand✅ If its settings mention WiFiDog. If not, put a SafeNet gateway or MikroTik in front of it: that works with every brand.

Before buying, search the model's manual or web page for "WiFiDog". "Captive portal" or "guest portal" alone is not enough: many routers only have their own click-through page, which can't check SafeNet codes.

1. Switch it on in SafeNet

  1. Open your siteIn SafeNet open Sites and click WiFiDog next to the site where the device will be.
  2. Switch it onClick Switch on WiFiDog. SafeNet shows the values the device needs. Most devices ask for them as separate fields:
    Server address (hostname){{ host }}
    Port{{ port }}
    SSL / HTTPSOff
    Path/wifidog/YOUR-SITE-CODE/ (yours is on the Sites page)
    Gateway IDAny name, different on each device (for example shop-1)
    Devices that want one address take the Authentication server URL: {{ wifidog_base }}/wifidog/YOUR-SITE-CODE/.
  3. Add packagesMake sure at least one package is sold at this site (or at "All sites") on the Packages page.

2a. OpenWrt and Cudy

  1. Install OpenWrtOn a Cudy, download OpenWrt for your exact model from Cudy's website and upload it in the router's firmware upgrade page. On other brands, check openwrt.org for your model.
  2. Make the guest Wi-Fi openIn LuCI (the OpenWrt web page) set the guest Wi-Fi's encryption to No encryption.
  3. Install WiFiDogConnect with SSH and run: 
    opkg update
opkg list | grep -i wifidog
opkg install apfree-wifidog     # or: opkg install wifidog
    Install whichever of the two your OpenWrt version lists.
  4. Point it at SafeNetFor wifidog, edit /etc/wifidog.conf: 
    GatewayID shop-1
GatewayInterface br-lan
AuthServer {
    Hostname {{ host }}
    SSLAvailable no
    HTTPPort {{ port }}
    Path /wifidog/YOUR-SITE-CODE/
}
CheckInterval 60
ClientTimeout 5
    br-lan is the network guests are on; use your guest network's interface if it is separate. For apfree-wifidog, enter the same server address, port and path in /etc/config/wifidogx or its LuCI page.
  5. Start it/etc/init.d/wifidog enable && /etc/init.d/wifidog restart (or wifidogx for apfree-wifidog).

2b. Comfast and Wavlink

  1. Update the firmwareNewer firmware is more likely to have WiFiDog.
  2. Find the portal settingIn the web page, look under Portal, Authentication, Web authentication or WiFiDog. Choose WiFiDog (it may be called third-party or external portal).
  3. Enter SafeNet's valuesServer address, port and path from step 1, SSL off, and a gateway ID if asked.
  4. Turn it on for the guest Wi-FiLeave that Wi-Fi open (no password). On a Comfast AC controller, apply it to the access points' guest SSID.

Menus differ between models and firmware versions. If yours looks different or asks for something not listed here, send support a screenshot.

3. Test it

  1. Check it is talking to SafeNetWithin a few minutes the WiFiDog box on the Sites page shows Access point last heard … min ago.
  2. Join the Wi-FiWith a phone, join the guest Wi-Fi and open any website. Your SafeNet login page appears.
  3. Log inMake a voucher (Vouchers → Generate) and type it. The phone gets online and shows on the Live page.

Login page doesn't appear? Check the guest Wi-Fi is open, the path ends with /, SSL is off and the port is {{ port }}. More in Troubleshooting.
