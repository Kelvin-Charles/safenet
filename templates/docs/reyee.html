This guide takes a Reyee access point (RG-RAP6262 and other RG-RAP… models) from the box to the first sale. You need only the access point, a PoE power adapter and an internet connection. Guests join your Wi-Fi, see your SafeNet login page, pay with mobile money (or type a voucher, or tap Try free), and are connected by themselves.

The access point is managed by Ruijie Cloud (Ruijie's free website and app). SafeNet talks to Ruijie Cloud for you: it creates the packages and the codes there, and reads who is online so you see them on SafeNet's Live page.

Adding another access point to a place that already works? Skip to Another access point at the same place: it takes five minutes and nothing changes in SafeNet.

What you need

  • The access point and a PoE power adapter (802.3at / PoE+), or a PoE+ switch. Check the box: some kits come without the adapter.
  • An internet router (fibre, 4G/5G router…) that gives addresses to connected devices (DHCP, as almost all do), and two network cables.
  • A smartphone with the Ruijie Cloud app (Play Store / App Store), or a computer.
  • A Ruijie Cloud account (free, at ruijienetworks.com or in the app). Use the same account for all your access points: SafeNet's keys belong to the account.
  • Ruijie Cloud API keys (App ID and App secret), once per account. Ruijie gives them on request: email service_rj@ruijienetworks.com (or ask your Ruijie distributor) saying it is for creating vouchers from your billing system. It can take a few days, so ask early. Already have keys for this account? Use the same ones.
  • A SafeNet account with the site (place) and at least one package.

1. Power it on and connect it

  1. Cable itRun a cable from the access point's LAN/PoE port to the adapter's PoE (or "AP"/"Data+Power") port. Run a second cable from the adapter's LAN port to a free port on your internet router. Plug the adapter into power.
  2. Wait for it to startIt takes about 2–3 minutes. When the light is steady, the access point is up and has internet through your router.
  3. Mount it laterTest everything on a table first, then mount it. Outdoor models: keep the cable entry facing down and use the waterproof cap that came with it.

A new access point shows a Wi-Fi called @Ruijie-m… (the last characters of its MAC address). You don't need to use it if you add the access point with the app as below. Its own web page is usually at 10.44.77.254 when you are on that Wi-Fi.

2. Add it to Ruijie Cloud

  1. Sign inOpen the Ruijie Cloud app (or the website) and sign in with your account.
  2. Create a project for the placeTap + / Add project and name it after the place (for example Kariakoo Shop). Use one project per place. For a place that already has a project, open it instead.
  3. Add the access pointIn the project choose Add device and scan the QR code on the access point's label (or type its serial number, SN, from the label or box).
  4. Wait until it shows OnlineThis takes a minute or two once it has internet. Still offline after 10 minutes? Check the cables and that the router gives internet.
  5. Update the firmwareOpen the device and choose Upgrade if a newer version is offered. Don't unplug it while it updates (about 5 minutes).

3. Make the guest Wi-Fi

  1. Add the Wi-FiIn the project open the Wi-Fi (WLAN/SSID) settings and add a network with your name, for example Kariakoo Free WiFi.
  2. No passwordSet security to Open. Guests must join without a password; the login page does the rest.
  3. Keep guests apartTurn on client isolation (guests can't see each other's phones) if your model offers it.
  4. Remove the default Wi-FiDelete or hide any other open Wi-Fi on this access point, so guests can't get around the login page.

4. Connect SafeNet to Ruijie Cloud

  1. Packages firstIn SafeNet open Packages and make sure the packages for this place exist (sold at this site or at "All sites"). You only make packages in SafeNet: SafeNet creates matching packages on Ruijie Cloud by itself.
  2. Open the siteOpen Sites. Add the place as a site if it isn't there yet, then click Reyee next to it.
  3. Enter the keysChoose your Ruijie Cloud server (if unsure, any: SafeNet finds the right one), enter the App ID and App secret, and click Connect.
  4. Pick the projectIf your account has several projects, choose the one you made in step 2 and click Use this project. SafeNet shows Project: … and the Ruijie packages it found or made (for example "SafeNet 1 day").
  5. Check the packagesIf a yellow box lists SafeNet packages with no Ruijie package, press Read packages. If it stays, create a Ruijie package with that duration in Ruijie Cloud (Authentication → Voucher → Package), then press Read packages again.

5. Put SafeNet's login page on the access point

  1. Download itIn the Reyee box on SafeNet's Sites page click Download login page (.zip). Keep the file as it is (don't unzip it).
  2. Create the captive portalIn Ruijie Cloud open the project, then Auth & Accounts → Captive Portal → Add (in some versions Authentication → Captive Portal). Set:
    • Policy mode: Cloud Auth
    • Authentication device: AP
    • SSID: your guest Wi-Fi from step 3
  3. Upload the pageUnder Portal Page click Add Portal Page, choose auth mode Custom HTML, click Upload and pick the .zip file. Save.
  4. Allow SafeNet before loginIn the captive portal's allowlist (walled garden / free URLs) add exactly one domain: {{ public_host }}. The login page loads your packages and takes payments from it. Save the captive portal.

    Add nothing else. Allowing captive.apple.com, google.com, gstatic.com or similar stops phones from opening the login page by themselves. Mobile money uses a PIN prompt on the phone, so no payment website is needed.

  5. Upload onceThe page fetches your packages, prices, logo, colour and offers from SafeNet every time it opens, so changes in SafeNet show up by themselves. Upload the .zip again only after you switch the free trial on or off (Captive portal → Free trial in SafeNet).

6. Test it

  1. Join the Wi-FiForget the Wi-Fi on your phone if you joined it before, then join it again. The login page with your logo and packages opens by itself. If it doesn't, open http://neverssl.com in the browser.
  2. Buy the cheapest packageChoose it, enter your mobile money number and confirm the PIN prompt on your phone. The page shows your code and connects you by itself within a few seconds. The code is also sent by SMS.
  3. Try a voucherIn SafeNet generate one voucher for this site (Vouchers → Generate). Wait a minute (SafeNet makes it on Ruijie Cloud first), then type it on a second phone.
  4. See it in SafeNetWithin a minute or two the guest shows on the Live page with the code, time left and data used, and the sale on Payments and the dashboard.

Another access point at the same place

  1. Power it and connect itAs in step 1, to the same router (or a switch behind it).
  2. Add it to the same projectIn Ruijie Cloud add it to the same project as the first one (step 2) and update its firmware.
  3. That's itThe project's Wi-Fi and captive portal apply to it by themselves, so guests get the same Wi-Fi name and the same login page. Nothing changes in SafeNet. Check in Ruijie Cloud that the new access point broadcasts your guest Wi-Fi.

At a different place? Make a new project for it in Ruijie Cloud, a new site in SafeNet, and follow steps 3 to 6 for that site (the same API keys work).

Good to know

  • Phones coming back with time left use the same code again if the login page opens; once their time is used up they see the packages to buy more.
  • Disabling a voucher in SafeNet doesn't reach Ruijie Cloud. To cut off a guest who is online, use Ruijie Cloud (Auth Clients).
  • Speed limits come from your SafeNet plans: SafeNet puts them on the packages it creates on Ruijie Cloud.
  • Hotspot sharing (a guest passing the Wi-Fi on from their own phone or PC) can't be blocked by a Reyee access point alone. A Reyee gateway router (RG-EG…) can: in Ruijie Cloud, Gateway → Advanced → TTL rule, TTL 1 for the guest network. Giving packages speed limits also makes sharing less worth it.
