Many routers, controllers and hotspot systems can check logins with a RADIUS server. SafeNet includes one, so these devices can accept SafeNet vouchers and customer accounts.

This only works if the location has a fixed public IP address (ask your internet provider). If it does not, use a MikroTik (VPN tunnel), Omada access points, or the SafeNet gateway box instead.

1. Add the router in SafeNet

  1. Find your public IPFrom the location, open a site such as ifconfig.me. That is the address SafeNet will see.
  2. Add a RADIUS clientIn SafeNet open RADIUS clients (NAS) → Add: the public IP, a short name, the vendor, and a secret (a long password, at least 6 characters).

2. Point the router to SafeNet

In your router's hotspot or RADIUS settings, enter:

RADIUS server{{ public_host }}
Authentication port1812
Accounting port1813 (turn accounting on, so SafeNet sees usage)
Secretthe secret you entered in SafeNet

Guests then log in on the router's own login page with a voucher code (as both username and password) or with a customer account from SafeNet's Users page.

3. Test it

Make a voucher (Vouchers → Generate) and log in with it. SafeNet's Auth Logs page shows every accepted or rejected login, which helps when something does not work.
