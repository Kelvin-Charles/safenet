Ruijie's enterprise access points have WiFiDog web authentication built in. You point them at SafeNet, and they send new guests to your SafeNet login page, let them online after they pay or enter a voucher, and check with SafeNet every minute or so. That check means SafeNet sees each guest's data usage and can cut them off the moment their time ends or you press Disconnect.

Which Ruijie devices work

DeviceWorks with SafeNet directly?
Ruijie enterprise access points: RG-AP820-L(V2), RG-AP820-L(V3), RG-AP840-L, RG-AP880 and other RG-AP… models✅ Yes, just the access point and internet
Reyee gateway routers: RG-EG… models, with any Reyee access point✅ Yes, through the router's WiFiDog setting
Reyee access points: RG-RAP… models on their own❌ No. Reyee access points only offer Ruijie's own login page. Add a Reyee gateway router, or use a SafeNet gateway box.

Buying new? Choose RG-AP820-L(V3) (indoor, Wi-Fi 6) rather than Reyee RG-RAP models if you want no extra box.

1. Switch it on in SafeNet

  1. Open your siteIn SafeNet open Sites and click Ruijie next to the site where the access point will be.
  2. Switch it onClick Switch on Ruijie access points. SafeNet shows the two values the access point needs:
    • Authentication server URL: looks like {{ wifidog_base }}/wifidog/Ab3xY…/ (yours is on the Sites page).
    • Portal server IP: {{ server_ip or 'shown on the Sites page' }}
  3. Add packagesMake sure at least one package is sold at this site (or at "All sites") on the Packages page.

2. Set up the access point

  1. Plug it inConnect the access point (or its PoE adapter's LAN port) to your internet router and wait until it has started.
  2. Create the guest Wi-FiIn the access point's web page or in Ruijie Cloud, create your guest Wi-Fi with no password (open). Note its WLAN ID (1 for the first Wi-Fi).
  3. Turn on web authentication with SafeNetOpen the access point's command line (eWeb → Command Line, or SSH/Telnet) and enter the commands from the Sites page. They look like this: 
    config
web-auth template safenet
 ip {{ server_ip or 'SAFENET_IP' }}
 url {{ wifidog_base }}/wifidog/YOUR-SITE-CODE/
 exit
wlansec 1
 web-auth portal safenet
 webauth
 end
write
    Use the exact url from your Sites page, and your Wi-Fi's WLAN ID after wlansec.
  4. Check it is talking to SafeNetWithin a few minutes the Sites page shows Access point last heard … min ago, and the dashboard lists it under devices.

Managed by Ruijie Cloud? Ruijie Cloud may overwrite settings made on the access point itself. Either remove the access point from Ruijie Cloud, or set the same values in Ruijie Cloud's captive portal settings (policy mode External, the authentication server URL above as the portal server URL, and the portal server IP). Firmware menus differ between models; if yours looks different, contact support with a screenshot.

3. Test it

  1. Make a voucherIn SafeNet: Vouchers → Generate, one voucher for 1 hour.
  2. Join the Wi-FiYour phone opens the SafeNet login page with your logo and packages. If not, open http://neverssl.com.
  3. Log inEnter the voucher. The access point lets you online and shows "You're online". The session appears on the Live page with its data usage.
  4. Try disconnectingPress Disconnect on the Live page. The phone loses internet within about a minute.

Good to know

  • The access point contacts SafeNet over the internet on port 5001. Nothing needs changing on your internet router.
  • Guests' login and payment pages use secure HTTPS.
  • Speed limits are set on the access point (per Wi-Fi or per user), not by SafeNet plans.
  • This setup follows the open WiFiDog standard. It has been tested with a simulated access point; for your first Ruijie installation, contact SafeNet support{% if support %} ({{ support }}){% endif %} so we can watch it connect.
