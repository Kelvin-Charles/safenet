UniFi access points are managed by a UniFi controller (the UniFi Network application). Its guest portal sends new guests to SafeNet's login page; after they pay or type a voucher, SafeNet asks the controller to let the phone online for the time they paid. SafeNet reads each guest's data usage from the controller and sends the phone back to the login page when the time is up.

You can use SafeNet's UniFi controller (nothing else to run) or your own (a Cloud Key, a UniFi gateway such as a UDM, or a computer running UniFi Network).

Option 1: SafeNet's controller (recommended)

  1. Switch it onIn SafeNet open Sites, click UniFi next to the site, type the Wi-Fi name guests will see and click Use SafeNet's controller. SafeNet makes the site, the open guest Wi-Fi and the login page.
  2. Plug in the access pointsConnect each one (or its PoE adapter) to your internet router.
  3. Point them at SafeNetFind the access point's address in your router's list of devices, connect with SSH (a new access point's user and password are both ubnt) and type: 
    set-inform {{ unifi_inform_url }}
    On Windows use PuTTY or ssh ubnt@192.168.1.20 in the command prompt; on a phone, an SSH app such as Termius. An access point already used elsewhere must be reset first (hold the reset button about 10 seconds).
  4. Add them in SafeNetBack in the UniFi box, enter the MAC address from each access point's label and click Add access points. They restart and start broadcasting your Wi-Fi within a few minutes.
  5. Add packagesMake sure at least one package is sold at this site on the Packages page.

Option 2: your own controller

  1. Make it reachableSafeNet must reach the controller from the internet (a public IP, or a port forward to port 8443, or 443 on UniFi OS consoles).
  2. Make a local adminIn UniFi: Admins & Users → add an admin with local access only (not a UI.com account, which needs two-step login). Give it full management of this site.
  3. Connect SafeNetIn SafeNet open Sites → UniFi → Your UniFi controller: the controller address (for example https://203.0.113.5:8443), the site short name from the controller's address bar (often default), and the admin's username and password.
  4. Turn on the guest portalIn UniFi: make the guest Wi-Fi open, and turn on the Hotspot (guest portal) for it with External portal server = {{ unifi_portal_ip or server_ip }} (UniFi only accepts an IP address here).
  5. Pre-authorization accessAllow {{ unifi_portal_ip or server_ip }}/32 (and {{ unifi_portal_host }} if it asks for names) before login, so phones can open the login page.

Test it

  1. Join the Wi-FiWith a phone, join the guest Wi-Fi. Your SafeNet login page appears.
  2. Log inMake a voucher (Vouchers → Generate) and type it. The phone gets online and shows on the Live page with its data usage within a minute; Disconnect sends it back to the login page.

Login page doesn't appear? Check the guest Wi-Fi has the hotspot portal on, the external portal server is SafeNet's, and SafeNet's address is allowed before login. Code accepted but no internet? The UniFi box on the Sites page shows the controller's error.
