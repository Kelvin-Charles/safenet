About RADIUS Attributes

RADIUS attributes are used to configure authentication, authorization, and accounting (AAA) for network users. This page lists all available standard and vendor-specific attributes that can be configured in plans and user profiles.

Note: When adding attributes to plans, use the format shown below. The operator (usually :=) assigns the value, while other operators like == are used for checking conditions.

Bandwidth Limit Configuration
Setting Bandwidth Limits

You can set bandwidth limits in two ways:

  1. Plan-level limits: Set default bandwidth limits for all users in a plan
  2. User-level limits: Override plan limits for specific users
Speed Format Examples
  • 10M - 10 Megabits per second
  • 100M - 100 Megabits per second
  • 1G - 1 Gigabit per second
  • 10M/10M - Upload/Download (MikroTik format)
Data Cap Format

Data caps are specified in GB (Gigabytes). The system automatically converts to bytes for RADIUS attributes.

  • 10 - 10 GB monthly limit
  • 100 - 100 GB monthly limit
  • 0 or empty - Unlimited
Tip: When bandwidth limits are set, the system automatically adds the appropriate RADIUS attributes (e.g., Mikrotik-Rate-Limit, Cisco-AVPair) based on the plan's vendor type.
Common Configuration Examples
Basic Internet Plan (10 Mbps, Unlimited Data)
Upload Speed: 10M
Download Speed: 10M

Premium Plan (100 Mbps, 500 GB Cap)
Upload Speed: 100M
Download Speed: 100M

MikroTik Router (Asymmetric)
Upload Speed: 10M/20M (MikroTik format)
Download Speed: (leave empty, included in upload)
Data Cap: 100
Note: Some vendors (like MikroTik) use combined upload/download format. Check your vendor's documentation for the correct format.
