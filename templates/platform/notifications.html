Where these files come from
  1. At console.firebase.google.com, create a project (e.g. SafeNet).
  2. Add an Android app with package name com.safezonetz.safenet_app and download google-services.json.
  3. Add an iOS app with bundle ID com.safezonetz.safenetApp and download GoogleService-Info.plist.
  4. For iPhones: in Apple Developer, Keys, create a key with Apple Push Notifications service, then upload the .p8 in Firebase: Project settings, Cloud Messaging, Apple app configuration.
  5. Project settings, Service accounts, Generate new private key: that file is the service account key. Keep it secret.

The app reads its settings from SafeNet when it starts, so no new app build is needed once these are uploaded. The files stay on the server (app files folder, readable only by SafeNet).
