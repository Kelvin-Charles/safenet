How to set up a business that's waiting
  1. In Ruijie Cloud (your account), create a project for the place (one per site; any name, e.g. USMART - TICD) and add the device by the serial number below. Update its firmware.
  2. Make the guest Wi-Fi open (no password), with the name the business asked for.
  3. Press Connect waiting businesses by serial number: SafeNet finds the project each access point is in (or pick it and press Use). It creates the packages on Ruijie Cloud and emails the business.
  4. Click Login page to download its .zip. In Ruijie Cloud: Captive Portal → Add, Cloud Auth, device AP, that Wi-Fi, Portal Page Custom HTML, upload the .zip, and allow only {{ allowed_host }} in the allowlist.
SafeNet asks Ruijie Cloud which project each business's access point is in. Businesses never see projects; a project already used by another site, or named after another business, is never given.
