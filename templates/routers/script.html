{% if router.vendor == 'mikrotik' %}

Open the router in Winbox or WebFig → New Terminal, paste all of this, and press Enter. Needs RouterOS 7. Set up your Hotspot (IP → Hotspot → Hotspot Setup) first if you haven't.

# SafeNet VPN + RADIUS for "{{ router.name }}"
/interface wireguard add name=safenet-wg private-key="{{ private_key }}" listen-port=13231 comment="SafeNet"
/interface wireguard peers add interface=safenet-wg public-key="{{ hub.public_key }}" endpoint-address={{ config.WG_ENDPOINT }} endpoint-port={{ hub.listen_port }} allowed-address={{ config.WG_SERVER_IP }}/32 persistent-keepalive=25s comment="SafeNet"
/ip address add address={{ router.tunnel_ip }}/16 interface=safenet-wg comment="SafeNet"
/radius add service=hotspot,login,ppp address={{ config.WG_SERVER_IP }} secret="{{ router.nas.secret if router.nas else '' }}" src-address={{ router.tunnel_ip }} authentication-port=1812 accounting-port=1813 timeout=3s comment="SafeNet"
/radius incoming set accept=yes
/ip hotspot profile set [find] use-radius=yes radius-accounting=yes radius-interim-update=1m
/ip hotspot user profile set [find] shared-users=1
/ppp aaa set use-radius=yes accounting=yes interim-update=1m

Check: /interface wireguard peers print should show a recent "last-handshake", and this page will say "Connected" within a minute. Speed limits from your plans are sent to the router as Mikrotik-Rate-Limit.
